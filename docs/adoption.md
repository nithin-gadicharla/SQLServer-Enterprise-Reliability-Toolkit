# Adoption and independent evidence

No independent adoption, usage counts, stars, citations, customer outcomes, or endorsements have been verified for this release candidate. This statement describes the evidence available to the project; it is not a claim about all possible external use.

Use the adoption issue template for voluntary, independently authored reports. Do not submit a report on someone else's behalf, invent organizations, request inflated claims, or exchange benefits for positive endorsements. A fork, download, star, or CI run does not establish operational adoption.

A publishable adoption entry needs: original public source URL; reporter identity or independent contact verification; permission to quote; toolkit version/commit; actual use case and duration; environment in non-sensitive terms; observed benefits and limitations; comparison method and raw evidence where possible; relationship to maintainer; and verification date. Reports may be negative. Redact confidential details and record uncertainty.

Only after verification add an entry to this file with a link to the independently authored source. Keep maintainer experiments in benchmarks, not in adoption records. Correct or retract entries if evidence changes. No outreach, endorsement requests, or invitations are sent automatically.
