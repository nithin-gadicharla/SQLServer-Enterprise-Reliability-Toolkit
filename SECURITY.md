# Security policy

Do not publish vulnerabilities, credentials, connection strings or sensitive diagnostic reports in public issues. Use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner privately through an existing verified channel to arrange disclosure. A private reporting service is not guaranteed by this file.

The current development line is 0.2.x; no support SLA or production certification is promised. Diagnostic output includes topology and security principal names. Store it with restrictive ACLs. Encrypted TLS validation is mandatory in the collector. Verification may produce substantial I/O and requires a separately approved identity. No telemetry is collected.
